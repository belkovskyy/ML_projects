# 08_time_series — Time Series

## Прогнозирование заказов такси

**Задача:** по истории почасовых заказов такси предсказать число заказов на следующий
час (регрессия на временном ряду).
**Цель:** RMSE на тестовой выборке не больше 48.

---

### Данные
- Ряд заказов такси, ресемплирован до шага 1 час.
- Разбиение по времени: **train / test = 90 / 10** (без перемешивания).

---

### Подход
- Анализ ряда: тренд, сезонность и остатки (декомпозиция), проверка стационарности,
  скользящие среднее и стандартное отклонение.
- Признаки: календарные (час, день недели), лаги, скользящее среднее.
- Гиперпараметры подбираются, модели сравниваются по RMSE на кросс-валидации по времени.

---

### Модели
- **CatBoost**, **LightGBM**, линейная регрессия. Dummy-модель — базовая точка отсчёта.

---

### Метрика и результат
**Метрика:** RMSE.

| модель | RMSE (валидация) | RMSE (тест) |
|---|---|---|
| **CatBoost** | **21.7** | **37.9** |
| LightGBM | 23.2 | 39.5 |
| линейная регрессия | 23.4 | 42.7 |
| dummy (базлайн) | — | 84.7 |

Лучшая модель — CatBoost, тест RMSE **37.9** при целевом пороге 48. Все модели заметно
превосходят dummy-базлайн (84.7).

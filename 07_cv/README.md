# 07_cv — Computer Vision

## Определение возраста покупателей по фото (Age Estimation)

**Задача:** по фотографии лица оценить возраст человека (задача регрессии).  
**Цель:** построить модель компьютерного зрения, которая предсказывает возраст с приемлемой ошибкой.

---

### Данные
- Датасет с фотографиями людей и разметкой возраста (`labels.csv`)
- Размер выборки: **7 591** изображение  
- Разбиение: **train 4 113 / valid 1 500 / test 1 978**

---

### Подход
- EDA: распределение возраста, примеры изображений, базовые выводы по датасету
- Предобработка + аугментации (train):
  - `RandomHorizontalFlip`, `RandomRotation`, `ColorJitter`
  - нормализация/препроцессинг из предобученных весов `torchvision` (`weights.transforms()`)
- Для valid/test — только препроцессинг (без аугментаций)
- Transfer learning на предобученных CNN (torchvision)
- Сравнение архитектур по **valid MAE**, финальная проверка — на test

---

### Модели
Проверены:
- **ResNet50** (pretrained)
- **EfficientNet-B0** (pretrained)

---

### Метрика и результат
**Метрика:** MAE (Mean Absolute Error), в годах.

Лучший результат:
- **ResNet50 — Test MAE ≈ 7.92**  
  (best **valid MAE ≈ 6.58**)

---

### Файлы
- `Определение возраста покупателей.ipynb` — полный ноутбук с EDA, обучением и оценкой качества

---

### Стек
- Python, NumPy, Pandas, Matplotlib
- **PyTorch / torchvision** (transfer learning)

## Классификация изображений одежды (Fashion-MNIST)

**Задача:** по изображению предмета одежды 28×28 в градациях серого определить его категорию — одну из 10 (задача многоклассовой классификации).
**Цель:** обучить свёрточную сеть и оценить точность на отложенной тестовой выборке.

---

### Данные
- Fashion-MNIST: **60 000** обучающих и **10 000** тестовых изображений 28×28, 10 классов
- Классы сбалансированы (по 6 000 на класс), от обучающих отделены **10 %** под валидацию
- Данные подгружаются с публичного зеркала при первом запуске

---

### Подход
- Обзор данных: баланс классов, примеры каждого класса
- Нормализация пикселей в [0, 1], тензоры, `DataLoader`
- Обучение с нуля, отбор по valid accuracy, финальная проверка на test

---

### Модель
- Свёрточная сеть: два блока **Conv → BatchNorm → ReLU → MaxPool** (1 → 32 → 64 канала) + полносвязная голова с Dropout

---

### Метрика и результат
**Метрика:** accuracy.

- **Test accuracy ≈ 0.910** (valid за 5 эпох: 0.877 → 0.920)
- Лучше всего распознаются брюки, сумка, ботинки, сандалии (f1 ≈ 0.98); основные ошибки — на похожих «верхних» вещах (рубашка / футболка / пальто)
